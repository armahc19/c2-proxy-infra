AUTHORIZED SECURITY LAB

Device-profile install test — for the operator's own test device only.

What this page is

This is the lab landing page for an authorized traffic-inspection test. It is not a real service, government site, or product page. The Download button serves a configuration profile that genuinely redirects and decrypts network traffic from the device it is installed on.

What the profile installs (6 payloads)

PayloadEffect on the device
Root CATrusting the lab mitmproxy — HTTPS from the device can be decrypted and logged by the lab gateway.
DNS over HTTPSAll DNS queries go to the lab DoH endpoint (LAB_DOH_HOST).
Global HTTP proxyFallback proxy path. Note: this payload type is honored on supervised devices only.
IKEv2 VPNFull-tunnel: all device traffic routes through the lab VPS (LAB_VPS_IP) using the generated per-device credentials.
SCEPRequests a device-identity certificate from LAB_MDM_HOST.
MDMAttempts MDM enrollment against LAB_MDM_HOST. With the default fake APNS topic this fails — that failure is the expected lab observation.

Before you install

  • Confirm the LAB_* values in server.py point at your lab infrastructure — the server prints a warning if placeholders are still set.
  • Use a test Apple account; do not sign into personal services (banking, mail, messaging) during the test.
  • Expect iOS to show an “Unsigned Profile” warning — the profile is not CMS-signed in this lab build.
  • Sync the strongSwan secret line from the server log into ipsec.secrets on the VPS before testing the VPN.

Install & remove

Install: tap Download → open Settings → Profile Downloaded → Install. Screens will name each payload before applying.

Remove: Settings → General → VPN & Device Management → tap the profile → Remove Profile. (On supervised devices the MDM payload, if it had enrolled, can be removed only by the MDM server — not applicable here since enrollment fails by design.)

Do not install this profile on: any device you do not own, a device shared with others, or a device signed into personal or work accounts. Removal of the VPN/proxy/CA payloads is manual; the CA trust must be re-checked after removal.
Operator note: the strongSwan EAP password for this device is in the server log (strongSwan secret: line). It changes only if VPN_SECRET_SALT or the victim ID changes.
